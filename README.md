# 🌍 World Tracking

A React application that helps you track the cities you've visited around the world. Mark locations on an interactive map, save your travel memories, and organize your journeys in one place.

**🔗 Live Demo:** https://world-tracking.vercel.app/

**📦 Repository:** https://github.com/Blessino/World-Tracking

---

## Preview

Track your travels by:

- 🗺️ Adding cities by clicking on the map
- 📍 Saving visited locations with notes
- 🌎 Viewing all visited cities and countries
- ⚡ Smooth navigation with React Router
- 📱 Responsive design for desktop and mobile

---

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Blessino/World-Tracking.git
cd World-Tracking
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Start the JSON server

```bash
npm run server
```

The app will run locally on:

- Frontend: `http://localhost:5173`
- API: `http://localhost:8000`
